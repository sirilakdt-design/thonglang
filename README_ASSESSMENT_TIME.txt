แก้ไขการแสดงวันที่และเวลาประเมิน ADL ครั้งที่ 1
- บันทึกเวลาไทย (Asia/Bangkok) เมื่อหมอสร้างผลประเมินใหม่ ลงคอลัมน์ created_at เดิม
- แสดงวันที่ที่เลือก + เวลาที่บันทึกจริง เมื่อเป็นวันเดียวกัน (ไม่แสดง 00:00 ที่เกิดจาก DATE)
- รายการย้อนหลังที่ไม่มีเวลาประเมินที่ยืนยันได้ แสดงเฉพาะวัน ไม่แต่งเติมเวลา
- แก้ไขหน้าแสดงผลหมอ/แคร์กิฟเวอร์ และ PDF ของหมอ
- ไม่ต้องรัน SQL เพิ่ม และไม่เปลี่ยนประวัติเดิม
