Thonglang - บัญชีที่ต้องลบ: Deputy Director, G1, G2, G3, G4, D1, Gee

1) สำรองไฟล์ระบบและฐานข้อมูล thonglang ก่อนทุกครั้ง
2) อัปเดตไฟล์ PHP ใน ZIP ไปยังโฟลเดอร์ระบบ (อัปโหลดทับไฟล์เดิมตามที่ใช้งาน)
3) ใน phpMyAdmin เลือกฐานข้อมูล thonglang แล้ว Import remove_named_accounts.sql
   ไฟล์นี้ลบ users.role = deputy_director ทั้งหมด และลบ users.username ที่ตรงกับชื่อที่ระบุ
   (ไม่สนตัวใหญ่/เล็กและช่องว่างหัวท้าย) พร้อมตรวจสอบรายชื่อที่ยังเหลือ
4) ถ้าเกิด Foreign Key error ให้หยุด: สำรอง/ตรวจข้อมูลที่อ้างถึงผู้ใช้ก่อน ไม่ปิด FK checks
5) บังคับผู้ใช้เดิมออกจากระบบและเข้าสู่ระบบใหม่ หากต้องการยกเลิก session ที่เปิดอยู่ทั้งหมด

สำคัญ: ภาพ 'Saved passwords' คือข้อมูลที่ Chrome / Google Password Manager บันทึกไว้
การลบบัญชีจากเว็บหรือฐานข้อมูลจะไม่ลบรหัสผ่านที่ Chrome เก็บไว้
ต้องเข้า Chrome > Settings > Google Password Manager > Passwords
ค้นหาชื่อเว็บไซต์และลบ credential สำหรับชื่อที่ระบุแต่ละรายการด้วยตนเอง

ไม่มีการเชื่อมต่อฐานข้อมูลหรือ Chrome ของผู้ใช้ผ่านไฟล์ ZIP นี้
บัญชีในฐานข้อมูลจริงจะถูกลบเมื่อรัน SQL และสำเร็จแล้วเท่านั้น
