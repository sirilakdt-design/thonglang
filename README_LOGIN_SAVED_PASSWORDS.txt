Thonglang — Login และ Chrome Saved passwords

ปรับ login.php ให้ autocomplete="off" ในฟอร์ม ชื่อผู้ใช้ และรหัสผ่าน
เป็นการขอลดการเติมข้อมูลอัตโนมัติเท่านั้น Chrome อาจไม่ทำตามสำหรับฟอร์มเข้าสู่ระบบ

รายการที่ขึ้นว่า Saved passwords ถูกเก็บใน Chrome/Google Password Manager ไม่ใช่รายการของเว็บไซต์
ไฟล์ ZIP หรือ SQL ไม่สามารถลบรายการนี้ในเบราว์เซอร์ของคุณได้

ลบรายการจาก Chrome:
1. เปิด Chrome > Settings > Google Password Manager > Passwords
2. ค้นหาโดเมน/เว็บไซต์ Thonglang ที่คุณใช้เข้าสู่ระบบ
3. เปิดรายการผู้ใช้ Deputy Director, G1, G2, G3, G4, D1 และ dee (ตามภาพ)
   หรือ Gee (หากมีบัญชีชื่อนี้ด้วย) และกด Delete แต่ละรายการ
4. รีเฟรชหน้า Login; หากเปิด Chrome Sync ให้ตรวจรายการที่ซิงก์ด้วย

คำเตือน: การลบ Saved passwords ไม่ใช่การลบบัญชีในฐานข้อมูลเว็บ
และ ZIP ฉบับนี้ไม่มีสิทธิ์แก้ข้อมูลรหัสผ่านที่บันทึกใน Chrome ของผู้ใช้
