อัปเดตตามภาพที่ผู้ใช้แจ้ง 22/09/2026

1) หน้ารายการผู้สูงอายุ
- เอาข้อความย่อย "ข้อมูลผู้สูงอายุในระบบ" และ "นามสกุล" ออกจากแถวข้อมูล
- เอาเส้นกรอบของป้ายอายุ / หมู่บ้าน / โรคประจำตัว และปุ่มจัดการในตารางออก
- กรณีไม่มีโรค แสดง "-" ตรงกลางโดยไม่ใส่กรอบ

2) การลบผู้สูงอายุ
- แก้ Error ที่อ้างถึงตาราง thonglang.caregiver ซึ่งไม่มีอยู่จริง
- ลบข้อมูลที่เกี่ยวข้องจากตารางที่มีอยู่จริงก่อน แล้วจึงลบ patient ภายใน transaction

3) แบบฟอร์มผู้สูงอายุ / บันทึกเยี่ยม
- เอาข้อความแนะนำ "หากมีหลายโรค..." ออก
- เอาข้อความแนะนำการเลือกตำแหน่งบ้านออก

4) หน้ามอบหมายผู้ดูแล
- "หมอผู้มอบหมาย" เปลี่ยนเป็นข้อความเรียบ ไม่มีกล่อง/กรอบ
- รายการมอบหมายเปลี่ยนจากการ์ดเป็นตารางคอลัมน์สำคัญ: ผู้สูงอายุ, อายุ, ผู้ดูแล, สถานะ, นัดครั้งถัดไป, จัดการ

5) หน้าสรุปการเข้าเยี่ยมของหมอ
- ถ้ายังไม่มีการประเมิน ADL: ไม่ให้กดดูสรุป และแสดง "ยังไม่ประเมิน"
- ถ้ามีการประเมินแล้ว: กด "ดูสรุป" ได้
- ปุ่ม "พิมพ์รายงาน" เปลี่ยนเป็น "พิมพ์"
- หน้าดูสรุปแสดงเนื้อหาแบบเดียวกับหน้าพิมพ์ผ่านมุมมองรายงาน
- หน้าพิมพ์เหลือปุ่ม "พิมพ์" เพียงปุ่มเดียว
