Thonglang - ลบผู้ใช้งานรอง ผอ. ออกจากระบบ

1. อัปโหลดไฟล์ PHP/CSS จาก ZIP นี้ทับไฟล์ระบบเดิม โดยสำรองไฟล์และฐานข้อมูลก่อน
2. ใน phpMyAdmin เลือกฐานข้อมูล thonglang แล้ว Import ไฟล์ remove_deputy_director.sql เพียงครั้งเดียว
   - ลบทุกบัญชีที่ users.role = deputy_director
   - ปรับ ENUM role ให้เหลือ admin, doctor, caregiver, director
   - SQL นี้ลบเฉพาะบัญชีรอง ผอ. ไม่ลบ ผอ., หมอ, แคร์กิฟเวอร์ หรือแอดมิน
3. ให้ผู้ใช้งานออกจากระบบและเข้าสู่ระบบใหม่หลังอัปเดต

ปรับแล้ว: เมนู/ฟอร์มจัดการผู้ใช้งาน ผอ. อย่างเดียว, รายชื่อ, สิทธิ์เข้าถึง
หน้าผู้บริหารและรายงาน, การเข้าสู่ระบบและ session ของรอง ผอ.

หมายเหตุ: การแก้ ZIP ไม่ใช่การเชื่อมต่อลบข้อมูลจากฐานข้อมูลจริงของเซิร์ฟเวอร์
ต้อง Import SQL เพื่อให้บัญชีรอง ผอ. ในฐานข้อมูลที่ใช้งานถูกลบด้วย
หาก SQL แจ้ง foreign key constraint อย่าปิด foreign key checks;
ตรวจและสำรองข้อมูลที่เกี่ยวข้องก่อนดำเนินการต่อ
